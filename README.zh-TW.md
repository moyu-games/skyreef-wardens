# 英雄亂鬥：雲礁之戰

[English](README.md) · **繁體中文**

在瀏覽器裡就能玩的即時卡牌塔防遊戲。組一副八張卡的牌組，把士兵和英雄派上雲端浮島戰場，在時間內打倒對手的塔。

**馬上玩：<https://moyu-games.github.io/skyreef-wardens/>**

不用安裝，也不用註冊帳號，進度存在你的瀏覽器裡。

---

## 特色

**對戰**
- 每場三分鐘，兩條路線，雙方各有兩座邊塔和一座主塔。
- 士兵、英雄和法術都有自己的動畫、命中特效和音效。
- 最後一分鐘潮光加倍，最後十秒畫面中央大字倒數。
- 可以和好幾種打法的電腦對手練習。

**雙人對戰**
- 開一個房間，把房間代碼或連結（`?room=代碼`）傳給朋友，就能即時對戰。
- 對戰中可以丟貼圖、快速嗆聲。

**養成**
- 收集卡牌、升級、累積獎盃。
- 寶箱、每 4 小時一個免費寶箱、每日商店。
- 每日簽到獎勵和每日任務。
- 三組牌組可以切換。

**介面**
- 以手機直向為主，電腦上也能玩。
- 第一場有新手教學，可以開關音效和震動，也有省電特效模式。

---

## 運作方式

整個遊戲就是一個靜態的 `index.html`，放在 GitHub Pages 上。畫面用 canvas 即時畫出來，音效用 Web Audio API 即時合成，所以不用下載任何圖片或音檔。

雙人對戰的訊息經過公開的 MQTT 中繼伺服器傳送。房間訊息沒有加密，知道房間代碼的人理論上看得到；遊戲只傳出牌和貼圖，不會傳任何個人資料。

頁面會比對 `version.txt`，有新版就自動重新整理，但不會在對戰途中重新整理。
